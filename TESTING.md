# CineMatch — Перевірка MVP

## Тест-кейси

| № | Перевірка | Очікуваний результат |
|---|---|---|
| 1 | Відкрити головну сторінку | Сторінка CineMatch завантажується на `127.0.0.1:8000` |
| 2 | Ввести `Interstellar` | Показуються результати пошуку |
| 3 | Ввести `Интерстеллар` | Пошук знаходить локалізовані результати TMDB |
| 4 | Ввести `дракон` | Показуються фільми за назвою або ключовим словом |
| 5 | Натиснути на результат | Фільм додається до «Сподобалося» |
| 6 | Оновити сторінку | Вибраний фільм залишається у списку через `localStorage` |
| 7 | Видалити фільм | Фільм зникає зі списку |
| 8 | Натиснути «Підібрати фільм» | Показуються схожі фільми |
| 9 | Натиснути рекомендації без вибраного фільму | З'являється повідомлення про необхідність додати фільм |
| 10 | Залишити поле пошуку порожнім | Запит не надсилається |

## Проблеми, знайдені після MVP

1. Не були встановлені `fastapi`, `uvicorn` і `httpx`. Виправлено встановленням залежностей.
2. Uvicorn запускався з `C:\Users\User`, тому не знаходив модуль `CineMatch`. Виправлено запуском із Desktop.
3. Пошук кириличними назвами працював гірше за англійський. Виправлено мультимовними запитами TMDB.
4. Пошук за тематичним словом не був реалізований. Виправлено через TMDB keywords і discover.

## Команди перевірки

```powershell
cd "$env:USERPROFILE\Desktop"
python -m py_compile CineMatch.py
python -m uvicorn CineMatch:app --reload
```

## Висновок

Основний User Flow працює: пошук → вибір фільму → список вподобаних → рекомендації.
