# CineMatch — Prompt Log

## Ключові промпти та результат

1. **«В чем проблема?»**
   - Перевірено файл і виявлено відсутні Python-залежності.

2. **«Где мне найти ключ TMDB?»**
   - Визначено спосіб отримання TMDB API key та його передачі через змінну середовища.

3. **«Теперь куда мне этот код?»**
   - Налаштовано запуск із PowerShell без запису API-ключа у вихідний код.

4. **«Русский или украинский ничего не выдаёт, а английский выдаёт»**
   - Реалізовано пошук TMDB трьома мовами: українською, російською та англійською.

5. **«Сделать поиск по ключевому слову, например дракон»**
   - Додано пошук ключових слів TMDB та отримання фільмів через `/discover/movie`.

6. **«Подходит ли код под критерии проекта?»**
   - Проведено перевірку MVP за критеріями та визначено відсутні Product Brief, User Flow, Prompt Log і тестову документацію.

7. **«Сможешь исправить?»**
   - Створено комплект документації для здачі та заплановано покращення обробки помилок.

## Ітерації розробки

### Ітерація 1 — базовий MVP

Створено FastAPI-застосунок із пошуком фільмів, списком вподобаних і рекомендаціями.

### Ітерація 2 — мультимовний пошук

Додано запити TMDB українською, російською та англійською мовами, а результати об'єднано без дублікатів.

### Ітерація 3 — пошук за ключовими словами

Додано пошук TMDB keywords і отримання фільмів, пов'язаних із тематикою запиту.
