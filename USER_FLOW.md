# CineMatch — User Flow

## Основний сценарій

1. Користувач відкриває CineMatch.
2. Вводить назву фільму або ключове слово, наприклад `дракон`.
3. Натискає кнопку пошуку або клавішу Enter.
4. Backend надсилає запити до TMDB українською, російською та англійською мовами.
5. Сайт показує знайдені фільми.
6. Користувач натискає на результат, щоб додати його до списку «Сподобалося».
7. За потреби користувач видаляє фільми зі списку.
8. Натискає «Підібрати фільм».
9. Backend отримує схожі фільми через TMDB API.
10. Сайт показує рекомендації з назвою, роком і описом.

## Альтернативні сценарії

- Якщо результатів немає, сайт показує повідомлення «Нічого не знайдено».
- Якщо список «Сподобалося» порожній, сайт просить спочатку додати фільм.
- Якщо TMDB API недоступний, застосунок використовує резервний список.
- Якщо API-ключ не заданий, базова версія працює з локальними резервними даними.

## Основна навігація та інтерактивні елементи

- поле пошуку;
- кнопка «Знайти»;
- кнопки результатів пошуку;
- кнопки видалення зі списку;
- кнопка «Підібрати фільм»;
- блок рекомендацій.
