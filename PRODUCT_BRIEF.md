# CineMatch — Product Brief

## 1. Визначення продукту

- **Назва:** CineMatch.
- **Цільовий користувач:** людина, яка хоче швидко знайти фільм для перегляду без довгого перегляду каталогів.
- **Проблема:** користувач часто не знає, який фільм обрати, або витрачає багато часу на пошук стрічок за назвою чи тематикою.
- **Рішення:** вебзастосунок приймає назву фільму або ключове слово, показує відповідні стрічки та формує рекомендації на основі вибраних фільмів.
- **Очікуваний результат:** користувач отримує короткий список релевантних фільмів і може обрати наступний фільм для перегляду.
- **Основна дія:** ввести назву або ключове слово, додати фільм до списку вподобаних і отримати рекомендації.

## 2. Функціональність

### Основні функції

- пошук фільмів через TMDB API;
- пошук українською, російською та англійською мовами;
- пошук за назвою та ключовими словами;
- додавання результату до списку вподобаних;
- видалення фільму зі списку;
- отримання схожих фільмів;
- збереження вибраних фільмів у браузері.

### Додаткові функції

- резервний список фільмів без API-ключа;
- повідомлення про відсутність результатів;
- локальне збереження стану через `localStorage`.

### Мінімальний MVP

MVP складається з однієї вебсторінки, FastAPI backend, інтеграції TMDB API, пошуку, списку вподобаних і блоку рекомендацій.

## 3. Технічна структура

- **Frontend:** HTML, JavaScript, Tailwind CSS CDN.
- **Backend:** Python, FastAPI.
- **API:** The Movie Database API.
- **База даних:** не потрібна для MVP; вибрані фільми зберігаються у `localStorage`.
- **Запуск:** `uvicorn CineMatch:app --reload`.

## 4. Очікуваний практичний результат

Користувач вводить, наприклад, `дракон`, бачить відповідні фільми, додає один або кілька результатів і отримує список схожих фільмів для перегляду.
